# Life Dashboard

A simple to-do list life dashboard built with HTML, CSS and vanilla JavaScript for Coding Camp.

## Features
- **Greeting** – live clock, date, and a greeting based on the time of day
- **Focus Timer** – 25-minute timer with Start, Stop and Reset
- **To-Do List** – add, edit, mark as done and delete tasks
- **Quick Links** – buttons that open your favorite websites

Everything is saved in the browser with Local Storage.

## Challenges
- Light / Dark mode
- Custom name in greeting
- Change Pomodoro time
- Prevent duplicate tasks
- Sort tasks

## Run it
Open `index.html` in any modern browser. No install or build step needed.
